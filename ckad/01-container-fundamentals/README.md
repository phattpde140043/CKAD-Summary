# Module 1 — Container Fundamentals

Module nền tảng gồm 4 bài học — trang bị kiến thức bắt buộc trước khi vào các
chủ đề CKAD chính. Tóm tắt từ video course CKAD của Sander van Vugt.

## Bài học

Mỗi bài học một file riêng; bài chưa có link nghĩa là chưa tạo file.

- [Bài 1 — Understanding and Using Containers](01-understanding-and-using-containers.md): container là gì, container registry, quản lý container, container logs + lab
- [Bài 2 — Container Images](02-container-images.md): kiến trúc image nhiều layer, tạo image bằng Dockerfile và docker commit + lab
- [Bài 3 — Kubernetes là gì](03-kubernetes-overview.md): cloud-native computing, orchestration, nguồn gốc Google Borg, CNCF & distributions, kiến trúc cluster & API resource thiết yếu + lab
- [Bài 4 — Kubernetes Deployment Options & Lab Environment](04-deployment-options-and-lab-environment.md): các lựa chọn triển khai (on-prem · managed cloud · AIO), cài Minikube trên Ubuntu VM/WSL, kubeadm all-in-one (tùy chọn), kubectl & ứng dụng đầu tiên + lab
