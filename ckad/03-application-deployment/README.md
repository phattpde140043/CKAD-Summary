# Module 3 — Application Deployment

Module về triển khai ứng dụng: chạy ứng dụng có **scalability** và **updates**
bằng **Deployment**, cũng như cài đặt ứng dụng trong môi trường Kubernetes.
Tóm tắt từ video course CKAD của Sander van Vugt — tương ứng course
*Certified Kubernetes CKAD: Application Deployment*.
